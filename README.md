# 🎬 Кадрик

Маленькая простая программа: перетаскиваешь видео в окошко — и оно режется на кадры (фото).

![panel](docs/screenshot.png)

## Что умеет

- 📂 Перетаскивание видео мышкой (drag & drop) или выбор по клику
- ✂️ Нарезка видео на кадры через `ffmpeg`
- ⏱️ Настройка частоты: сколько кадров в секунду вытаскивать
- 🖼️ Формат на выбор: PNG или JPG
- 📌 Окно всегда поверх других программ и не сворачивается
- ⬇️ Кнопка «Обновить» — авто-обновление из репозитория
- 💾 Сохранение настроек

Кадры складываются в папку `Mamonov/kadrik/имя_видео_frames` в домашнем каталоге (папки создаются автоматически).

## Установка

### 1. Установи ffmpeg

- **Windows:** скачай с [ffmpeg.org](https://ffmpeg.org/download.html) и добавь в PATH
- **macOS:** `brew install ffmpeg`
- **Linux:** `sudo apt install ffmpeg`

### 2. Установи зависимости Python (опционально — для drag & drop)

```bash
pip install -r requirements.txt
```

> Без `tkinterdnd2` перетаскивание мышкой не работает, но выбор файла по клику работает всегда.

## Запуск

```bash
python kadrik.py
```

## Как пользоваться

1. Запусти программу.
2. Перетащи видео в окошко (или кликни, чтобы выбрать).
3. Готово — кадры появятся в папке рядом с видео.
